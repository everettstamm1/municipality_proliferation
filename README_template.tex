\section*{Overview}

This replication package contains the Stata and R code used to construct the analysis data and reproduce the tables and figures for the municipality proliferation project. The main entry point is \path{code/master.do}. That file sets all paths, writes \path{paths.csv} for R scripts, runs the Derenoncourt replication setup used by this project, constructs cleaned/interim datasets, and then runs the analysis scripts that write tables to \path{exhibits/tables} and figures to \path{exhibits/figures}.

The current code is organized around an external data directory rather than a \path{data/} directory inside the Git repository. In \path{code/master.do}, \path{$DROPBOX} is currently set to \path{D:/munis_replication/} for user \path{Everett Stamm} and \path{F:/munis_replication/} for user \path{edog9}. The code then expects:

\begin{itemize}
  \item \path{$DROPBOX/data/raw} for raw inputs.
  \item \path{$DROPBOX/data/interim} for generated intermediate files.
  \item \path{$DROPBOX/data/clean} for final cleaned analysis files.
  \item \path{$DROPBOX/data/xwalks} for crosswalk inputs and generated crosswalks.
\end{itemize}

The exact default data root at the time of this draft is \path{D:/munis_replication/data}. A replicator should edit the path block at the top of \path{code/master.do} before running the code.

\section*{Computational Requirements}

\subsection*{Software Requirements}

The main code is Stata and R. \path{code/master.do} declares \path{version 17.0}, so Stata 17 or newer is recommended. The master file currently points to R 4.4.2 on one machine and R 4.3.1 on another via \path{$Rterm_path}. The code has hard-coded Windows paths; no Linux/macOS run was verified while preparing this README draft.

\begin{itemize}
  \item Stata 17 or newer.
  \item R, currently configured for R 4.4.2 or R 4.3.1 depending on username.
  \item Stata community packages can be installed by running \path{do code/setup_stata_packages.do} from the repository root. The setup script installs the Stata packages used by the active project code and by the edited Derenoncourt replication scripts, including \path{rsource}, \path{statastates}, \path{estout}, \path{ivreg2}, \path{ranktest}, \path{reghdfe}, \path{ftools}, \path{parmest}, \path{unique}, \path{labutil}, and related plotting/table utilities.
  \item R packages used by scripts called from \path{master.do}: \path{tidyverse}, \path{sf}, \path{haven}, \path{tigris}, \path{stringr}, \path{readxl}, \path{terra}, and \path{glmnet}. Some scripts install missing R packages from CRAN, which requires internet access.
  \item The NCES pre-generation comments use the Stata package \path{educationdata}. If those commented downloads are reactivated, document the package version and source queries.
\end{itemize}

\subsection*{ODBC Setup for Census of Governments}

\path{code/cleaning/cog_cleaning.do} uses Stata's \path{odbc} commands for two Census of Governments inputs. The machine running the replication must have an ODBC driver that matches the Stata architecture. For 64-bit Stata on Windows, install the 64-bit Microsoft Access Database Engine / Access ODBC driver if it is not already available, then open the 64-bit ODBC Data Source Administrator at \path{C:/Windows/System32/odbcad32.exe}. For 32-bit Stata, use the 32-bit administrator at \path{C:/Windows/SysWOW64/odbcad32.exe}.

\section*{Description of Programs and Code}

\path{code/master.do} is the master script. It performs the following steps:

\begin{enumerate}
  \item Sets user-specific paths, Stata version, Stata globals, and the ado path.
  \item Writes \path{paths.csv}, which several R scripts read to recover Stata global paths.
  \item Copies edited Derenoncourt setup scripts into the Derenoncourt replication directory via \path{code/cleaning/dcourt_file_setup.do}.
  \item Runs the edited Derenoncourt replication master file at \path{$RAWDATA/dcourt/replication_AER/code/0_MASTER_edited.do}.
  \item Runs cleaning scripts under \path{code/cleaning}.
  \item Runs analysis scripts under \path{code/analysis}.
\end{enumerate}

\subsection*{Cleaning Code}

The cleaning stage constructs crosswalks, Derenoncourt-derived inputs, municipal counts, Census/IPUMS/NHGIS-derived controls, spatial covariates, school and court-order inputs, and the final clean analysis datasets. Key outputs are \path{data/clean/cz_pooled.dta}, \path{data/clean/mechanisms.dta}, \path{data/clean/panel_a_data.dta}, and \path{data/clean/pcarrow_fig_data.dta}.

\subsection*{Analysis Code}

The analysis stage reads the cleaned datasets and writes manuscript and appendix outputs to \path{exhibits/tables} and \path{exhibits/figures}. Stata helper programs in \path{code/ado} produce repeated table formats and shift-share/segregation calculations.
